# Компилятор модов — Forge 1.20.1

Изолированная Gradle-сборка для модов Minecraft 1.20.1 / Forge 47.4.10 / Java 17.
Она не меняет генератор модпака в корне репозитория.

## Сборка
Из корня репозитория: `cd "компилятор модов"`, затем `gradle build --no-daemon`
(Gradle 8.8; JDK 17; первый запуск загружает ForgeGradle и Forge).
Готовый результат: `build/libs/mca-tinkers-compat-0.1.0-alpha.jar`.

Также есть GitHub Actions workflow **Compile Forge mods**, который собирает JAR
и прикрепляет артефакт к workflow run. Зависимости MCA и TConstruct при запуске
игры должны быть установлены отдельно.

## Важно
Это **исходная заготовка для дальнейшей разработки**, не полная интеграция:
- добавлены данные MCA о подарках для перечисленных Tinkers-предметов;
- НЕ реализованы выбор экипировки, AI инструментов, рыбалка, поддержка
  всех будущих предметов TConstruct или специальные действия инструментов.
- Все эти функции требуют патчей исходной логики MCA и игрового тестирования.

Не считайте успешно собранный JAR подтверждением совместимости.
