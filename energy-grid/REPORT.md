# Проверка сборки 0.4.0

NeoForge 21.1.268 и Java 21 запустили чистый сервер со стартовым миром, собственным аддоном и серверными модами итогового профиля. FTB Quests загрузил десять глав, девятнадцать заданий и два файла локализации. Все девятнадцать заданий содержат предметные награды. Сборщик дважды сформировал побайтно одинаковый архив. Размеры и хеши сверены с 27 внешними JAR и встроенным аддоном.

## Измерено на острове

Тестовый игрок поставил углегенератор Powah! и три кабеля до магнетита. На первом угле баланс достиг $3 через 600 рабочих тиков. Автоматический тест купил уголь за $3 и передал его в топливный слот для второго цикла. Два угля дали по $12. После ручной покупки итоговый баланс составил $21.

Предпросмотр оставил баланс прежним. Из $21 склад использовал $15 на пять углей и сохранил $6. Повторная проверка не списала деньги. При 40 единицах пшеницы автоматическая продажа дала $2 и оставила защищённые 32. Повторная продажа не затронула остаток. Конечный баланс — $8.

Тест использует отдельный служебный мод с FakePlayer. В пользовательском архиве его нет. Для второго запуска применялось игровое ускорение tick sprint, поэтому 30 секунд — эквивалент при 20 TPS. Это время от начала генерации до возможности купить следующий уголь.

## Клиент и поздние этапы

Prism Launcher 11.1.1 открыл итоговый файл в чистом профиле, распознал встроенный аддон 0.4.0, развернул стартовый мир и начал скачивать внешние моды. Сетевые запросы клиента к CDN завершались ошибкой Network unreachable. Полный запуск из чистого клиентского профиля остаётся неподтверждённым.

Контракты интегрированы с API Data Center, Money и FE. Приёмка реактора и турбины использует данные сформированного многоблока Mekanism. Испытание с настоящей работающей серверной стойкой, поздним реактором, отрисовкой экранов, аварийным перезапуском и полным прохождением всех наград не проведено. Верхние пределы позднего экспорта и модели дохода в BALANCE.md расчётные. Сборка ориентирована на одного игрока в приложенном мире. Исходная кампания не переносится автоматически в произвольный новый мир.
