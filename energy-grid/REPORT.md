# Проверки прототипа «Первый платёж»

## Измерено на Minecraft Java 1.21.1

Мир извлечён из итогового ZIP и запущен на локальном выделенном сервере Mojang под Java 21. Тестовый клиент подключился и получил стартовое сообщение датапака. Печь и кабели поставлены командами тестового стенда. Клиент использовал те же команды терминала, которые выполняют кнопки в чате игрока.

| Событие | Измерение |
|---|---:|
| Первый пуск → первая выплата | 20,00 с |
| Стартовое сообщение → первая выплата на стенде | 21,00 с |
| Второй пуск, на купленном угле → выплата | 20,00 с |
| Баланс после первой выплаты, закупки и второй выплаты | 5 → 2 → 7 монет |

21 секунда включает установку блоков командами. Время игрока, который берёт комплект из сундука, собирает печь и прокладывает линию вручную, ещё не измерено.

Локальная проверка `verify.py` прошла. Она дважды собирает архив, сравнивает байты и сверяет фиксированные версии, структуру, локализацию, ссылки на функции и расчёт экономики.

## Prism Launcher

Чистый Prism Launcher 11.1.1 запущен с итоговым ZIP. Лаунчер дошёл до диалога импорта. Импорт не подтверждён: экземпляр не появился в тестовом профиле, а журнал зафиксировал ошибку DNS при загрузке индекса `meta.prismlauncher.org`. Minecraft с NeoForge внутри этого профиля не запускался.

## Не проверено

Ручное прохождение в одиночной игре из Prism, восстановление после смерти, прерывание линии и сохранение в середине цикла ещё не измерены. Проверки снабжения, серверных контрактов и реактора относятся к полной версии.
