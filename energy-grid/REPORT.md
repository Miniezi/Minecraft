# Проверка сборки 0.3.0

| Проверка | Результат |
|---|---|
| 27 сторонних файлов | Скачаны по ссылкам из манифеста. Размеры, SHA-1 и SHA-512 совпали. |
| Собственный аддон | Gradle 8.12.1 и JDK 21 собрали JAR. NeoForge обнаружил и загрузил `energogrid_export` 0.3.0. |
| Сервер NeoForge | В чистом мире под Java 21 загрузился весь набор серверных модов. Mouse Tweaks предназначен для клиента. |
| Стартовый пустой мир | Начальная площадка и точка появления (0.5, 81, 0.5) проверены серверным стендом. |
| FTB Quests | Загрузилась одна глава и один квест. Условие квеста связано с достижением `energogrid:first_sale`. Интерфейс книги в клиенте ещё не проверен. |
| Стартовая энергетика | Реальный углегенератор Powah!, три кабеля и магнетит с FE-входом аддона. Проверен экспорт на общую учётную запись Money и списание $3 за доставленный уголь. |
| Чистый Prism и Java-клиент | Формат `.mrpack` подтверждён на 0.2.0. Для 0.3.0 проверены структура, все URL и хеши, а также сервер с файлами из архива. Полный импорт с загрузками и запуск клиентского профиля этой версии ещё не подтверждены. |

Стенд поставил блоки и загрузил одну единицу угля программно. На закупку $3 накопилось за 600 рабочих тиков, около 30 секунд при 20 TPS. За весь цикл одна единица угля принесла $12. После покупки следующего угля осталось $9. Это измерения от начала работы генератора. Время ручной сборки линии не измерялось.

SkyWorlds 0.2.1 падает на старом варианте пустого мира с явным слоем воздуха. Приложенный мир использует пустой список слоёв. После исправления сервер инициализировал мир без этого сбоя. Автоостровы и сезоны SkyWorlds отключены, поскольку сборка использует свою стартовую площадку.

## Границы версии

Терминал и FE-счётчик используют API Money, который также задействуют Tycoon Exchange и Data Center. У островного счётчика фиксированный тариф. Собственная Grid Connection Tycoon Exchange оставлена для рыночных сделок. Продажа через неё, резерв батарей для контрактов, специализированные задания дата-центра и контракты не пройдены игровым тестом. Автозакупки по правилам запаса и полноценная многоступенчатая прогрессия ещё не реализованы.

NeoForge 21.1.268 поднят до версии, удовлетворяющей требованиям установленных модов. SHA-256 официального установщика `6e9da1f350ab34b303ebdec2d446389bd176632d84b61f7ba52eb5a80086c8ff`. Хеши всех модов перечислены в [MODLIST.md](./MODLIST.md) и [mods.lock.json](./mods.lock.json).
