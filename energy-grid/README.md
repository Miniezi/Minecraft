# Энергосеть — Небесный контракт

Сборка 0.3.0 для Minecraft Java 1.21.1, NeoForge 21.1.268 и Java 21. Установщик содержит стартовый мир, русское меню, первую главу FTB Quests и собственный аддон. Внешние моды скачивает Prism по закреплённым ссылкам.

## Установка в Prism

1. Выберите «Добавить сборку → Импорт» и укажите `Energy-Grid-Skyblock-RU.mrpack`. Для установки требуется интернет.
2. В Prism 11.1 или новее проверьте окно источников. В нём могут появиться официальные ссылки CurseForge и собственный JAR `energy-grid-export-0.3.0.jar`. Версии и контрольные суммы указаны в [списке модов](./MODLIST.md).
3. Запустите экземпляр с Java 21 и откройте мир «Энергосеть — Небесный контракт» в разделе одиночной игры. На острове уже есть площадка для генератора, счётчик, сундук с комплектом и книга «Терминал энергосети».

Обновление из 0.2.0 импортируйте отдельным экземпляром. Первый цикл 0.3.0 рассчитан на приложенный стартовый мир. Старый баланс счётчика 0.2.0 в счёт Money не переносится.

## Первая продажа

1. Из сундука возьмите **Углегенератор (Начальный)**, три **Энергокабеля (Начальный)** и уголь.
2. Поставьте углегенератор на золотую плитку. Поставьте по энергокабелю на каждую из трёх оранжевых плиток к востоку, в сторону магнетита. Магнетит у края линии — счётчик.
3. Положите уголь в топливный слот генератора. Когда счётчик примет первые 4 000 FE, на счёт Money поступит $1. При начислении $3 можно купить следующий уголь. Для работы счётчика игрок должен находиться рядом с площадкой.
4. Возьмите терминал в руку и откройте ПКМ. В меню **Счёт** видны доступные средства и выручка от счётчика. В разделе **Магазин → Купить уголь** списывается $3. При полном инвентаре покупка отклоняется.
5. Команда `/trigger eg` выводит те же разделы в чат. Через неё можно вернуть потерянную книгу. В FTB Quests начальная глава «Первый платёж» привязана к событию первого оплаченного экспорта.

Тариф островного счётчика фиксирован. Лимит — 200 FE/тик. Tycoon Exchange предоставляет собственную Grid Connection с рыночным тарифом. Терминал, островной счётчик, Tycoon Exchange и поддерживаемые выплаты Data Center используют счёт Money.

## Сборка из исходников

С JDK 21 и Gradle 8.12.1 выполните из корня репозитория:

```sh
gradle -p energy-grid/addon build
python3 energy-grid/build.py
python3 energy-grid/verify.py
```

Готовые файлы появятся в `dist/`. [mods.lock.json](./mods.lock.json) фиксирует версии, источники, хеши и зависимости. `verify.py --staged-mods ПУТЬ` также сверяет скачанные JAR с манифестом. В [отчёте](./REPORT.md) описаны тесты и оставшиеся интеграции.
