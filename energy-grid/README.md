# Энергосеть — Небесный контракт 0.4.0

Одиночная кампания для Minecraft 1.21.1, NeoForge 21.1.268 и Java 21. Импортируйте файл Energy-Grid-Skyblock-RU.mrpack в новый экземпляр Prism Launcher. Разрешите скачивание закреплённых файлов. В одиночной игре выберите приложенный мир «Энергосеть — Небесный контракт».

## Первые 20 минут

1. Откройте сундук у кафедры. Поставьте начальный углегенератор Powah! на золото, три кабеля Powah! — на оранжевые плитки между генератором и магнетитом. ПКМ по генератору, положите уголь в топливный слот. Оставайтесь возле станции.
2. На каждые 4 000 FE счётчик перечисляет $1. Откройте книгу «Терминал энергосети» правой кнопкой, выберите «Квесты и награды», затем заберите награду первого задания. Команда /trigger eg открывает главное меню повторно.
3. Когда на счёте появятся $3, купите один уголь в разделе «Магазин → Ресурсы острова». Положите его в генератор. «Счёт» показывает деньги Money, выручку, расходы и последние сделки.
4. Для первой автоматической доставки используйте обычный стартовый сундук в точке −2, 81, 2. Малый склад заказывает при остатке меньше четырёх углей, стремится приобрести до восьми и оставляет $6. Сначала нажмите «Предпросмотр». При балансе $21 он может доставить пять углей за $15. Для физической подачи в генератор подведите предметную трубу Pipez со стороны сундука и настройте извлечение ключом Pipez.
5. Накопитель стоит $60, солнечная панель $80, ветрогенератор $135. Солнечная или ветровая ветка освобождает от части расходов на уголь. Накопитель позволяет перенести экспорт на вечер. На вкладке склада включите вечерний тариф.
6. Для серверной ветки купите стойку, сборочный верстак и совместимые комплектующие. Для короткого хостинга примите заказ в терминале и заработайте первый доллар самой стойкой. Хранение и вычисления требуют собственную назначенную стойку, работающий сервер, сетевое подключение и отдельный питающий накопитель снизу. Условия, ход выполнения и причина простоя доступны в разделе заказов.
7. Для ветки Mekanism наладьте биотопливо, затем химическую переработку. Квесты приёмки работающего реактора и турбины проверяются по ПКМ по их корпусам. Ветка Immersive Engineering доступна параллельно.

## Сборка

Используйте JDK 21, Gradle 8.12.1 и Python 3. Из корня репозитория выполните

```sh
gradle -p energy-grid/addon build
python3 energy-grid/verify.py
```

При наличии закреплённых JAR Mekanism, Mekanism Generators и Data Center переменная ENERGY_GRID_MODS может указывать на их каталог. Архив создаётся в dist. Для существующего экземпляра русские главы и переводы находятся в config/ftbquests/quests. Задания, связанные с операциями станции, требуют аддона и датапака соответствующего релиза. Сохраните резервную копию перед переносом конфигурации.
