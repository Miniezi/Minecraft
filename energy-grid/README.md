# Энергосеть — Небесный контракт

Первый прототип для Minecraft Java 1.21.1, NeoForge 21.1.172 и Java 21. Механика первого контура реализована датапаком. Энергия моделируется счётчиком внутри датапака в условных единицах. Интеграции FE, сторонние моды и FTB Quests предстоит подключить после проверки первого контура.

## Сборка архива

Из корня репозитория выполните `python3 energy-grid/build.py`. Результаты появятся в `dist/`. Python 3 использует только стандартную библиотеку. Главный файл — `Energy-Grid-Skyblock-RU.mrpack`. Сборка также создаёт нативный ZIP Prism и отдельный ресурспак. Архивы воспроизводимы в одинаковом окружении. Мир создаётся из исходников и содержит только начальные настройки. Блоки острова появляются при первом входе.

Prism сам получает Minecraft и NeoForge при импорте или первом запуске. Архив содержит только собственные файлы проекта. Если Prism не может скачать компоненты сразу, на этапе «Downloading game files» можно выбрать «Skip». Лаунчер создаст экземпляр, а компоненты загрузит при первом запуске с доступом к сети. Зависимость загрузчика зафиксирована в манифестах обоих форматов и опубликована в [официальном Maven NeoForge](https://maven.neoforged.net/releases/net/neoforged/neoforge/21.1.172/). [Документация Prism по импорту](https://prismlauncher.org/wiki/getting-started/download-modpacks/).

## Первые 20 минут

1. В Prism откройте «Добавить сборку → Импорт» и выберите `Energy-Grid-Skyblock-RU.mrpack`. Запустите экземпляр на Java 21, затем откройте одиночный мир «Энергосеть — Небесный контракт».
2. Откройте сундук у кафедры. Заберите верстак, 8 булыжников, 3 блока вощёной резной меди и уголь. Возьмите книгу «Терминал энергосети» в руку и нажмите ПКМ. В книге есть станция, магазин, счёт, диагностика и восстановление.
3. На верстаке соберите печь. Поставьте её на золотую плитку. Над каждой оранжевой плиткой между печью и магнетитом поставьте по блоку вощёной резной меди. Линия отходит на восток.
4. Оставьте уголь в инвентаре и выберите в книге «Станция → Запустить цикл». Следите за счётчиком над панелью предметов. Через 400 рабочих тиков чат покажет оплату и новый баланс.
5. Купите уголь через «Магазин → Купить уголь». После списания трёх монет снова запустите цикл. Ожидаемый баланс после второго цикла — 7 монет.
6. Если линия разорвана, откройте диагностику. Если вы упали в пустоту и потеряли комплект, откройте «Восстановление». Терминал поможет восстановить оборудование, а при балансе ниже 3 монет может запустить аварийный цикл после ремонта.

Команда `/trigger eg` открывает те же разделы кнопками в чате. Потерянную книгу можно вернуть через «Восстановление → Заменить потерянную книгу» в меню чата. Книга выдаётся один раз и игрокам, уже начавшим прохождение с предыдущим датапаком.

## Расчёт прототипа

| Показатель | Значение |
|---|---:|
| Стоимость первого оборудования | Стартовый комплект |
| Топливо | 1 уголь / цикл |
| Цена купленного угля | 3 монеты / цикл |
| Продолжительность | 400 рабочих тиков, 20 с при 20 TPS |
| Принятая энергия | 20 000 условных единиц / цикл |
| Базовый тариф | 1 монета / 4 000 условных единиц |
| Выручка | 5 монет / цикл |
| Прибыль на купленном топливе | 2 монеты / цикл |

Игроку нужно оставаться в радиусе 24 блоков от центра. Цикл приостанавливается при разрыве линии. Закрытый мир и пропуск ночи не добавляют рабочие тики. Баланс и остаток цикла хранятся в scoreboard мира.

## Проверка

`python3 energy-grid/verify.py` проверяет содержимое ZIP и `.mrpack`, разделы меню и соответствие расчётной экономики командам датапака. Он не заменяет запуск в Prism и проверку игрового цикла.
