# Data Center in the Sky 1.6.0 — русская локализация

Для выпуска [Data Center in the Sky 1.6.0](https://www.curseforge.com/minecraft/modpacks/data-center-in-the-sky/files/9083204), Minecraft 1.21.1, NeoForge 21.1.248.

- `overrides/config/ftbquests/quests/lang/ru_ru.snbt` — локализация книги заданий, включая главы, квесты, задачи и награды.
- `overrides/resourcepacks/dcits-ru/` — дополнения к встроенным переводам блоков, предметов, меню и подсказок. Здесь же переводы книг Patchouli и страниц GuideME.
- `overrides/options.txt` — начальный язык `ru_ru` и включённый ресурспак.

## Установка

**Новый профиль.** Импортируйте локализованный ZIP как сборку в CurseForge. При первом запуске профиль получит русский язык и активный ресурспак.

**Уже установленный профиль 1.6.0.** Закройте игру. Скопируйте папки `config` и `resourcepacks` из `overrides` в каталог экземпляра. Откройте игру и выберите русский язык в настройках языка и `Русская локализация Data Center in the Sky 1.6.0` в меню наборов ресурсов. Это позволит сохранить существующие настройки графики и управления.

Если вы устанавливаете для группы игроков на выделенном сервере, положите файл `ru_ru.snbt` также в серверную папку `config/ftbquests/quests/lang/` и перезапустите сервер.

## Источники

- Сборка и файлы модов из манифеста CurseForge. При наличии используется русский текст из самих модов.
- Дополнительные строки из [репозитория Mekanism](https://github.com/mekanism/Mekanism/tree/1.21.x) для ключей с совпадающим английским текстом. Лицензия MIT указана в ресурспаке.
- Отдельные строки из [MPLOCmods v43](https://modrinth.com/resourcepack/mploc_mods/version/4Ph6g1ML), лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Доступный исходный текст этого ресурспака находится в архиве по ссылке.
- Страницы AE2 и AE2 Wireless Terminals из [Applied Guide Translations 1.0](https://modrinth.com/resourcepack/applied-guide-translations/version/1.21.1), лицензия AGPL-3.0-or-later. Здесь добавлены языковой путь `_ru_ru` и якоря для совместимости с английскими ссылками. [Исходный проект](https://github.com/Zilibobiksus/AppliedGuideTranslations).
- Строки, для которых не было готового перевода, переведены автоматически. Часть терминологии и стартовых квестов вычитана вручную.

Файлы проверены на совпадение ключей и сохранение подстановок. Полный запуск Minecraft и прохождение квестов не проверялись. Названия модов и моделей оборудования могут отображаться в оригинале. На экранах, где мод выводит текст непосредственно из кода, могут остаться английские надписи.
