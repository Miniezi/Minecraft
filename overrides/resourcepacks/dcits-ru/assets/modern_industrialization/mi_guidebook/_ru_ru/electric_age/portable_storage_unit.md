# Переносной накопитель

Переносный блок хранения (PSU) может быть создан для транспортировки энергии в вашем запасе.

<Recipe id="modern_industrialization:electric_age/battery/portable_storage_unit_asbl" />

По умолчанию, у него нет емкости для хранения энергии. Чтобы добавить емкость, вам нужно заполнить его батареями, либо направо нажав на PSU с батареями, либо направо нажав на батарею с ним. Чем выше уровень батареи, тем больше емкости они добавят к хранилищу.
