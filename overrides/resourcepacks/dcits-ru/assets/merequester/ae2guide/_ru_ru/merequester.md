<a name="getting-started"/>

## Начало

Чтобы начать, разместите <ItemLink id="requester"/> и подключите его к своей сети.
Логика [Autocrafting](ae2:ae2-mechanics/autocrafting.md) расположена в. Она должна размещать ваш
[Crafting CPU](ae2:ae2-mechanics/autocrafting.md#the-crafting-cpu) и <ItemLink id="ae2:pattern_provider"/>

<RecipeFor id="requester"/>

Для того чтобы <ItemLink id="requester"/> работал, нужно убедиться, что предметы или жидкости, которые вы хотите держать на складе, имеют закономерность
Именно так и можно создать их, если вы их запросите в качестве игрока.
[ME System](ae2:getting-started.md#your-very-first-me-system).

<a name="configuration"/>

## Конфигурация

Когда вы впервые открываете <ItemLink id="requester"/>, вы увидите обзор настройки запроса.
Каждый ряд интерфейса GUI представляет собой индивидуальный запрос.
<br/>


<a name="toggle-switch"/>

### Переменный переключатель

В ящике слева переключается запрос, настроенный на этом строке.
Запрос не будет выполнен.<br/>
Это может быть использовано для временного отключения конкретного запроса или для предотвращения выпуска <ItemLink id="requester"/> рабочих мест в процессе
Вы все еще делаете изменения в ряду.
<br/>


<a name="what-to-stock"/>

### Что хранить

Второй столб вы можете указать, что вы хотите сохранить на складе.
С помощью правого клика вы можете установить сумму до 1 или левого клика, чтобы использовать сумму, которую имеет стэк.
При перетаскивании ведра с жидкостью в слот можно использовать правый клик, чтобы настроить содержащуюся жидкость, или левый клик, чтобы настроить саму ведро.
Вы также можете переключить на элементы, чтобы быстро настроить тип элемента. Если у вас нет желаемого элемента в инвентаре, вы также можете перетащить и
Выбросить его с просмотров рецептов, которые поддерживаются Applied Energistics.
<br/>


<a name="amount-to-stock"/>

### Сумма в запасе

Количество на запас поле указывает, сколько запасать. Укажите, что запасать сначала, а затем введите желаемое значение.
поле будет адаптироваться к типу. Например, показывая `B` для указания ведра для жидкости.<br/>
Когда текущий запас падает ниже указанного объема, <ItemLink id="requester"/> запросит больше.
<br/>


<a name="batch-size"/>

### Размер партии

В следующем поле ввода указывается размер партии, который будет запрошен, когда текущий запас упадет ниже порога, указанного в
Сумма в поле запасов.<br/>
Это может быть использовано для уменьшения давления на [Crafting CPU](ae2:ae2-mechanics/autocrafting.md#the-crafting-cpu) и машины, используемые на судне
Поскольку полная сумма будет запрошена сразу, а не столько же отдельных рабочих мест.
<br/>


<a name="submit-button"/>

### Сдать кнопку

Чтобы применить изменения к запросу, введите желаемые значения в полях Количество на запас и размер партии, а затем нажмите Enter или нажмите
Нажмите на любой другой ряд, чтобы восстановить значения в предыдущем состоянии.
<br/>


<a name="status-bar"/>

### Стрижка статуса

В строке ниже входных ящиков и кнопке отправки отражается текущий статус запроса.

<a name="statuses"/>

## Статусы

Следующие статусы отображаются в строке статуса для каждого запроса.
<br/>


<a name="gray---empty"/>

### Серая - пустая

Текущий ряд отключен или ничего не указано.
<br/>


<a name="green---idling"/>

### Зелёный - безработный

Целевая сумма запаса уже достигнута или нет шаблона для запроса, который был настроен.
<br/>


<a name="red---missing-ingredients"/>

### Красный - отсутствующие ингредиенты

В системе отсутствуют необходимые ингредиенты для выпуска текущей работы.
Система.
<br/>


<a name="yellow---crafting"/>

### Желтый - ремесленный

В настоящее время разрабатывается желаемый запрос. Заявитель ждет завершения работы.<br/>
Пока этот статус активен, настройки для соответствующего запроса внутри <ItemLink id="requester"/> заперты и не могут быть изменены.
<br/>


<a name="purple---exporting"/>

### Фиолетовый - Экспорт

<ItemLink id="requester"/> получил все результаты текущей работы и пытается экспортировать их в систему хранения. <br/>
Этот статус обычно не виден. Если он активен слишком долго, значит в системе хранения недостаточно места.
<br/>


<a name="block-appearance"/>

### Внешний вид блока

Если любой запрос в <ItemLink id="requester"/> имеет какой-либо статус, кроме пустого или пустого, он изменит его внешний вид.

<a name="terminal"/>

## Терминал

Мод также предоставляет новый терминал под названием <ItemLink id="requester_terminal"/>. Он позволяет получить доступ ко всем <ItemLink id="requester"/>
в той же сети из центральной точки.

Терминал имеет те же функции, что и <ItemLink id="ae2:pattern_access_terminal"/> и позволяет искать конкретный запрос.
Поскольку все <ItemLink id="requester"/> имеют одно и то же имя по умолчанию, все запросы будут группированы под
Если вы хотите отдельную группу <ItemLink id="requester"/> в <ItemLink id="requester_terminal"/>, вы можете переименовать их в
с лопатой или с <ItemLink id="ae2:name_press"/>.
